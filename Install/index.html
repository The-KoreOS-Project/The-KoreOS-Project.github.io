Requirements

  • qemu
  • qemu-system-x86_64

How to use

In the directory with the .iso file, run:

qemu-system-x86_64 -cdrom KoreOS-v0.1.4.1.iso -m 1024

This starts a QEMU VM that runs the .iso with 1GiB of RAM assigned to it.
