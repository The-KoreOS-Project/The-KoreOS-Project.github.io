KoreOS: An Indie Linux Distro

KoreOS is an independent systemd-free Linux distribution designed to be adapt to use as daily drive and to give the best User Experience. KoreOS is in its early stages of developement and new releases come every 1-2 weeks. Any release can be found on the Install page (link in topbar) or the official GitHub repository.
The name KoreOS comes from Core, which in my native language means "Heart".
